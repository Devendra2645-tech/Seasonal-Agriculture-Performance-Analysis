# Seasonal Agriculture Performance Analysis

## Project Overview

This project analyzes agricultural performance across different seasons, crops and geographical regions using data analysis, statistical methods and visualization.

The analysis focuses on identifying seasonal patterns, crop performance, resource usage, environmental relationships, economic outcomes and disease/pest risk.

## Objectives

- Analyze agricultural performance across seasons
- Compare crop yield and production
- Study environmental factors
- Analyze resource usage and water efficiency
- Compare revenue, cost and profit
- Identify relationships between agricultural variables
- Perform statistical analysis
- Generate evidence-based agricultural insights

## Dataset

The dataset contains 4,000 records and 28 attributes related to:

- Location
- Crop
- Season
- Farm characteristics
- Environmental conditions
- Soil properties
- Nutrient usage
- Irrigation
- Fertilizer and pesticide usage
- Yield and production
- Revenue, cost and profit
- Water usage and efficiency
- Disease and pest risk

## Technologies Used

- Python
- Pandas

- Matplotlib

- SciPy
- Statsmodels
- Jupyter Notebook / Google Colab

## Key Findings

- Kharif recorded the highest average yield.
- Kharif recorded the highest average production.
- Kharif recorded the highest average profit.
- Zaid recorded negative average profit.
- Sugarcane achieved the highest average yield and production.
- Chilli recorded the highest average profit.
- Sugarcane was the highest-yielding crop across all three seasons.
- Profit showed a statistically significant difference across seasons.
- Water-use efficiency showed a strong positive relationship with yield.
